Specs
=====


We are building a node js server and front end react app to manage various os services.
The app will support the following capabilities

1. The scaffolding that hosts other applications underneath with ability to switch
2. A window manager that will allow the user to switch between applications
   1. List the windows that are open
   2. If a window is a chrome window, the tabs open will be listed using the chrome api
   3. The windows are shown as a tree
   4.  The windows can be sorted in multiple ways
   5. Click on a window to bring it to the front


Server
------
A nodejs server to act the backend for the above application. Each main area of capability should
be in different files
